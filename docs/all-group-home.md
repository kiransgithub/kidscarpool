# Personal all-group Home and five-tab navigation

KCP Home answers the next-ride question across every group the member belongs to. A parent no longer has to switch to the correct school, music, club or sports group before seeing an assignment.

## Primary navigation

```text
Home
Schedule
Requests
Groups
More
```

Points, Calendar and Settings live under More. Group administration remains inside Groups.

## Home

- next ride across all groups
- next ride assigned to the current user
- group badge on every ride
- up to three requests requiring the user's action
- no schedule-version or pending-change metrics for read-only viewers

## Schedule

The agenda is sorted chronologically across all groups. A group filter narrows the view without changing the active management context.

## Requests

The feed combines:

- open cover requests the current driver can accept
- accepted cover requests involving the current user
- the user's pending availability request
- availability requests awaiting Owner/Admin review

## Privacy and authorization

The RPCs begin from the current user's active memberships. They do not grant access to unrelated groups. Existing Row-Level Security and action-specific RPC authorization remain authoritative.
