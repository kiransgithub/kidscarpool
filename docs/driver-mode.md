# Driver mode

Driver mode is a full-screen, one-handed workflow available to the assigned driver and a group administrator.

## Sequence

```text
Confirm ride
Start ride
Account for each child
Navigate to destination
Report arrival
Confirm completed
```

## Child accountability

While the ride is In progress, each child must be marked:

```text
Picked up
or
Not riding
```

A Not-riding action requires a reason. For groups that require safety profiles, destination arrival is blocked until every child is accounted for.

## Driver tools

- Apple Maps navigation to pickup and destination
- parent or emergency-contact call action
- pickup tag
- seating requirement
- critical transportation alert
- pickup instructions
- ride issue reporting

## Reliability

Every child, arrival and issue event has a unique client event ID. Retrying the same event after a slow connection cannot create a duplicate.

## Privacy

The driver snapshot is available only to the assigned driver within the authorized ride window or to a group administrator. Opening the snapshot also invokes the sensitive roster audit path.
